## target: 做一个轮询linux机器的功能，确保在线状态正常

现有机器：4台不同云的linux机器


### 20251101

1. 首先我想到的是原生的ssh，但用起来错误日志显示等不太方便 -> 了解到python paramiko可以替代实现
2. paramiko用的user、password去连接，但是感觉用密码不安全，容易泄露 -> 用密钥去连接
    - 生成密钥：`ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519 -N ""`
    - 预先对所有机器进行一次ssh-copy-id操作: `ssh-copy-id -i ~/.ssh/id_ed25519.pub user@root`
    - paramiko通过本机的私钥与公钥进行连接
3. 执行ssh-copy-id操作时也需要输入密码，存在密码泄露的风险，到最后还是绕不过
    对于目前的环境，只能考虑先将数据存到本地，后续存储到数据库中，从数据库中读取数据
    所以第2步可以暂时不需要搞
